# Simple Healthcheck App

Простое Node.js приложение с поддержкой эндпоинта `/health` для деплоя на PaaS (Render / Railway).

## Описание проекта

Приложение написано на Express.js и содержит:
- Эндпоинт `/`, возвращающий приветственное сообщение.
- Эндпоинт `/health`, возвращающий статус `200 OK` и текущую временную метку (используется для проверки работоспособности платформой деплоя).

## Инструкция по деплою и CI/CD

1. **CI (GitHub Actions):** При каждом пуше или пулл-реквесте в ветку `main` запускается пайплайн, который проверяет зависимости и прогоняет тесты (`npm test`).
2. **Деплой:** Приложение задеплоено на платформу **Render** (или **Railway**) с использованием предоставленного `Dockerfile`.
3. **Защита от сломанного деплоя:** Автоматический деплой настроен так, чтобы срабатывать только после успешного прохождения GitHub Actions (зеленый CI).
