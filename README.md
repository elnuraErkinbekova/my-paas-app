# Simple PaaS Healthcheck App

Простейшее веб-приложение на Node.js (Express) с поддержкой эндпоинта проверки здоровья (`/health`), предназначенное для автоматического деплоя на PaaS-платформы (Render) с интеграцией CI-проверок.

---

## Технологии
* **Node.js** & **Express** — серверная часть и маршрутизация.
* **GitHub Actions** — автоматический CI (прохождение тестов).
* **Render** — облачная PaaS-платформа для непрерывного деплоя (CD).

---

## API Endpoints
* `GET /` — Главная страница приложения.
* `GET /health` — Эндпоинт проверки состояния (возвращает статус `200 OK`).
